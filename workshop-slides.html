Session 1 · Teaching

What is Artificial Intelligence?

In simple words

AI systems learn patterns from data and help with tasks like writing, classifying, recommending, and generating code.

Useful types for builders

  • Generative AI — writes text, code, explanations
  • Machine Learning — predicts labels/scores from examples
In this workshop we use both: an ML classifier + Gemini generative AI.
Session 1 · Teaching

What is vibecoding?

Building software by describing what you want in plain language, generating code with an LLM, then testing and improving quickly.

Describe idea→ Write prompt→ Generate code→ Run & fix→ Ship

You still need

  • Clear thinking
  • Testing
  • Basic debugging

AI helps with

  • Boilerplate code
  • Faster iteration
  • Explanations & rewrites

Session 2 · Critical Concept

Gemini ≠ Kaggle training

Gemini Flash-Lite

  • Generative AI
  • Accessed with an API key
  • Great at writing & explaining
  • Not trained on your CSV through the API

Separate ML model

  • Trained on Kaggle-style dataset
  • Learns Positive / Negative patterns
  • Exports to model.json
  • Used for prediction inside the app
Final product = ML prediction + Gemini explanation/reply.
Session 3 · Prompt Engineering

The 3-part prompt formula

1. Role

Who should the AI act as?

“Act as a senior Next.js engineer…”

2. Goal

What exact outcome do you want?

“Build ReviewRadar with Analyze button…”

3. Constraints

Stack, style, limits, format.

“TypeScript, Tailwind, one page UI…”

Prompt quality matters more than which chatbot logo you use.

Session 4 · Demo Roadmap

8 steps we will demonstrate

  1. API key — Google AI Studio for Gemini
  2. Idea → prompt — convert the product idea into instructions
  3. Code generation — GPT / Claude / DeepSeek
  4. VS Code setup — paste, install, run locally
  5. Dataset — small labeled CSV from Kaggle-style data
  6. Train ML model — Logistic Regression → model.json
  7. Integrate Gemini — explanation + polite reply
  8. Test & deploy — verify flow, ship on Vercel
Teaching Checkpoint

How the system works

Input

User pastes a customer/product review into the web app.

ML Model

Classifies text as Positive or Negative using patterns learned from dataset examples.

Gemini

Reads the review + prediction, then writes an explanation and suggested reply.

Participants should be able to explain this architecture in one sentence before we deploy.
Teaching · Dataset

What makes a good workshop dataset?

Keep it small & clear

  • Text + label columns
  • About 2,000–5,000 rows is enough
  • Labels like 0/1 or negative/positive

What we teach with it

  • Clean / prepare data
  • Train a simple classifier
  • Export model for the app
