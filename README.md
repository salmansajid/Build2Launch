# Build2Launch — Vibecoding & AI Workshop Kit

Everything you need to run tomorrow’s 2-hour workshop as a first-time trainer.

## Start here tonight
1. Open **`TONIGHT_CHECKLIST.md`** and complete it before sleeping
2. Skim **`TRAINER_PLAYBOOK.md`** (your minute-by-minute plan)
3. Keep **`SPEAKING_SCRIPT.md`** nearby if you freeze
4. Use **`PROMPTS.md`** for copy-paste live prompts
5. Share **`PARTICIPANT_HANDOUT.md`** as a PDF at the end
6. Keep **`reviewradar-backup/`** ready as your safety-net demo app

## Demo project
**ReviewRadar** — paste a review → ML sentiment → Gemini explanation + reply → deploy on Vercel

This matches the brief:
- Gemini for generative AI features
- Separate ML model trained on dataset-style CSV
- VS Code development
- LLM code generation
- Vercel deployment
