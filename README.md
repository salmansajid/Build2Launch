# Build2Launch — Vibecoding & AI Workshop Kit

Materials and demo app for the 2-hour Build2Launch workshop.

## Start here
1. Open **`TONIGHT_CHECKLIST.md`** and complete setup
2. Skim **`WORKSHOP_PLAYBOOK.md`** (minute-by-minute plan)
3. Keep **`SPEAKING_SCRIPT.md`** nearby during delivery
4. Use **`PROMPTS.md`** for copy-paste live prompts
5. Share **`PARTICIPANT_HANDOUT.md`** as a PDF at the end
6. Use **`reviewradar-backup/`** as the live demo app

## Demo project
**ReviewRadar** — paste a review → ML sentiment → Gemini explanation + reply → deploy on Vercel

This matches the brief:
- Gemini for generative AI features
- Separate ML model trained on dataset-style CSV
- VS Code development
- LLM code generation
- Vercel deployment
