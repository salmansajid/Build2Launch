## Slide 9 — Live Demo Steps

# Step-by-Step Demonstration

1. **API Key Generation** — Google AI Studio for Gemini
2. **Idea Generation** — turn an idea into a development prompt
3. **Code Generation** — GPT / Claude / DeepSeek
4. **Development Setup** — VS Code + run the app
5. **Dataset Collection** — small relevant dataset from Kaggle
6. **Model Training / Integration** — prepare dataset, train/fine-tune ML model, integrate
7. **AI Integration** — connect Gemini for AI-powered functionality
8. **Testing & Deployment** — test and deploy on Vercel

---

## Slide 10 — Important Technical Note

# How the AI pieces fit together

- **Gemini Flash-Lite** = generative AI via API  
  (explanations, replies, smart features)
- **Kaggle dataset** = used to train a **separate** ML model
- Both are integrated into one application where appropriate

> Gemini is not directly trained on a Kaggle dataset through its API.
